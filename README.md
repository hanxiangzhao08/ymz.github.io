# 毒危爆商品标题风险识别工具

纯规则网页工具，支持单条识别以及不少于 10,000 条 Excel/CSV 批量标题筛查。

## 业务口径

- “毒”指易制毒化学品；“危”指危险化学品；“爆”指易制爆危险化学品。
- 商品标题仅用于风险召回。仅标题命中时进入人工复核，不直接作为最终法定认定。
- 最终判断仍需标准化学名称、CAS号、浓度、物态、组分或SDS等事实，并由法定目录及确定性规则执行。
- 易制爆维度形成命中或候选时，危险化学品维度同步进入相同或更严格的管控状态。
- 上传文件只在访问者浏览器中解析和计算，默认不上传到服务端。

## 部署

GitHub Actions 在部署时自动：

1. 获取危险化学品目录机器转录；
2. 修正已核验的序号转录问题；
3. 校验2015版1—2828连续、无缺号和重号；
4. 应用2022年柴油调整；
5. 追加2026年新增5项；
6. 生成内置2,833条危化规则的静态页面；
7. 发布到GitHub Pages。

若目录结构校验失败，部署会中止，不会发布伪完整规则库。
